# BPM 測量小工具

可以測量節奏(BPM)的小工具。新增小工具時選擇「BPM 測量」即可放置。

## 測量方式

- **點擊測量**: 跟著節奏點擊按鈕,會依最近 16 次的間隔算出 BPM。
- **依時間軸或通知的速度測量**: 將時間軸(首頁・本機・社群・全域・媒體・中繼)或通知的到達速度(最近 1 分鐘的則數)顯示為 BPM。
- **用滑桿設定**: 可以用滑桿(對數)或輸入數字在 1〜100000BPM 之間設定並播放。

## 節拍器

可以用測得的 BPM 播放節拍器。可以選擇聲音,並可在小工具中開關。

BPM 沒有上限(聲音最多每秒 100 拍)。變更速度後會立即以新速度播放,在未檢視的分頁中也不會變慢。重新載入頁面後,操作畫面即可開始播放。
