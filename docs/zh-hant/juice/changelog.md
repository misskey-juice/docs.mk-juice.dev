# 更新日誌

關於 misskey-juice 中 JUICE 獨有功能的主要更新日誌。不包含源自官方 Misskey 的變更內容。完整歷史記錄請參閱 [GitHub 發布頁面](https://github.com/misskey-juice/misskey-juice/releases)。

> [!note]
> 本頁面為手動更新,可能無法及時反映[日語更新日誌](../../juice/changelog.md)的最新內容。如需最新資訊,請同時參閱日語頁面(或上方 GitHub 發布頁面)。

## v2026.10.0-juice+4.6

- 歡迎頁面的外觀新增「juice」樣式([JUICE 入口頁面](./entrance.md))。可以在控制台的品牌中與原版的 classic・simple 切換。與伺服器介紹・註冊並列,一覽使用者・線上・已連線伺服器・貼文的數量、本地時間軸、熱門、動態、部分已連線的伺服器。設定了背景圖片 URL 時,會鋪滿整個頁面並使面板半透明
- [聯邦診斷](./federation-diagnosis.md)的「帶簽章取得使用者資訊」現在會顯示簽章金鑰的類型(區分 RSA(金鑰長度)・Ed25519・ECDSA)。「inbox(傳送目標)的回應」改為用不帶簽章的空 POST 檢查,修正沒有 inbox(404 等)時也顯示正常的問題
- 歡迎頁面彩色「申請加入」按鈕上的 JUICE 徽章改為填滿顯示,更容易看清
- 給開發者: `admin/federation/diagnose-instance` 的每個項目新增 `keys`,inbox 不接受傳送時回傳 `inboxNotFound`。`admin/update-meta` 的 `entrancePageStyle` 新增 `juice`

## v2026.10.0-juice+4.5

- 從設定 → 帳號資料進行的匯入現在可以改為需要管理員核准([匯入核准](./import-approval.md))。在 JUICE 設定中選擇的類型(預設只有追隨,也可以選擇靜音・封鎖・清單・天線)的匯入會成為申請,管理員核准後才會匯入。可以查看自己申請的狀態・駁回理由,待審查的申請可以撤回
- 新增匯入申請的審查畫面。可以從控制台和「工具」選單開啟,查看檔案開頭的行・總數・依伺服器統計的數量後核准・駁回(附理由)。可以審查的是版主,以及擁有新角色政策「核准或駁回匯入申請」的人
- [繪畫聊天](./draw-room.md)的房間現在可以填寫說明(最多 10 行・512 字)。會顯示在房間清單中的名稱下方,在房間內可以透過「房間說明」按鈕查看
- 給開發者: 新增 `admin/import-requests/{list,show,approve,reject}`・`import-requests/{list,cancel}`。`i/import-*` 現在會回傳 `requiresApproval`。`juice/public-settings`・`admin/juice/settings` 新增 `importApprovalRequiredTypes`,`draw-rooms/create`・`update` 新增 `description`

## v2026.10.0-juice+4.4

- 在已聯邦伺服器的資訊(`/instance-info/<host>`)中新增「診斷」分頁(給版主)。依序檢查本伺服器的設定與狀態,以及對對方伺服器的實際請求,顯示聯邦在哪裡中斷(不會向對方傳送任何內容)。詳情請參閱[聯邦診斷](./federation-diagnosis.md)
- [塗鴉](./doodle.md)的縮時回放現在也會追蹤圖層顯示方式的變更,以及繪製線條以外的操作(移動・旋轉・縮放・翻轉・刪除・復原・重做等)(此更新之前的操作不追蹤)。現在可以疊加浮水印預設。裁切畫布現在也可以從範圍工具選取的範圍・選取範圍列・圖片選單開始
- 為[繪畫聊天](./draw-room.md)和塗鴉的畫布大小新增適合像素畫的 32×32・64×64・128×128,並將大小下限改為 16。重新進入曾以繪畫者身分參加的房間時,現在會從觀看狀態開始
- [天線](./antenna.md)的接收來源現在可以選擇「來自已追隨使用者的貼文」
- [使用其他伺服器表情符號的回應](./reaction-enhancements.md)現在以虛線邊框顯示,便於與本伺服器的表情符號區分。修正跟隨回應後直到重新載入才反映的問題
- 修正小說閱讀器直排時因寬度導致左側文字被截斷的問題。修正浮水印 QR 碼中間的大頭貼無法載入時一直停在載入中的問題
- 給開發者: 新增 `admin/federation/diagnose-instance`(`write:admin:federation`)。`draw-rooms/create` 的 `canvasPreset` 新增 `pixel32`・`pixel64`・`pixel128`,`canvasWidth`・`canvasHeight` 的下限改為 16

## v2026.10.0-juice+4.3

- 為[塗鴉](./doodle.md)新增[縮時回放](./doodle.md#縮時回放)。依序回放畫過的線條(10〜60 秒),並可產生影片下載・儲存到雲端硬碟・發布為貼文。畫布現在可以用與裁切圖片相同的操作裁切或擴展
- 只有內文的[小說](./novel.md)貼文因過長被摺疊時,顯示「以小說模式閱讀」而不是「顯示更多」。小說閱讀器中章節標題(`[chapter:…]`)現在顯示為標題。修正直排時不加分隔線、以章節標題開始的章節接在上一章後面顯示的問題
- [繪畫聊天](./draw-room.md)中,房主將人移出繪畫者時現在可以填寫理由(只告知被移出的本人)。修正顯示全域地圖時無法在地圖旁空白處繪畫的問題(塗鴉也是)
- [JUICE 設定](./settings.md)中新增用 disposable-email-domains 清單拒絕拋棄式電子郵件地址的設定(預設關閉)。電子郵件地址驗證時如果無法連線 verifymail.io・Truemail,不再阻止註冊,而是改為伺服器自身的驗證
- 給開發者: `draw-rooms/kick` 新增 `reason`(只傳送到被移出本人的串流中的 `memberLeft`)。`admin/juice/settings`・`admin/juice/update-settings` 新增 `disposableEmailBlocklistEnabled`・`disposableEmailAllowDomains` 等

## v2026.10.0-juice+4.2

- 修正繪畫聊天的圖層選單中出現後面沒有內容的分隔線的問題,以及已結束房間中圖層欄的隱藏按鈕沒有靠右的問題

## v2026.10.0-juice+4.1

- 給開發者: 新增 `notes/novel-text`(傳入 `noteId`・`fileId`,回傳 `name`・`data`(base64))。雲端硬碟檔案新增 `novelDownloadDisabled`,貼文新增 `novelTextProtected`,`i/update` 新增 `avatarDecorations[].scale`
