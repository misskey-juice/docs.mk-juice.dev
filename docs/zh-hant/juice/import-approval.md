# 匯入核准

可以將從設定 → 帳號資料進行的匯入改為需要管理員核准的功能。需要核准的匯入不會立即執行,而是成為申請,在管理員確認並核准後才會匯入。

## 需要核准的匯入

在控制台的 JUICE 設定「匯入核准」中選擇需要核准的類型。預設只有追隨,也可以選擇靜音・封鎖・清單・天線。

## 審查者

可以審查的是版主,以及擁有角色政策「核准或駁回匯入申請」的人。這些人自己的匯入無需核准,會直接執行。

## 申請(給使用者)

- 需要核准的類型的匯入按鈕會變為「匯入(需要核准)」。選擇檔案並匯入後,會作為申請受理。
- 在設定 → 帳號資料的「匯入申請」中,可以查看自己申請的狀態(待審查・已核准・已駁回・已撤回)以及被駁回時的理由。
- 待審查的申請可以透過「撤回」撤回。
- 同類型的申請仍在待審查時,無法提出新的申請。
- 申請被核准・駁回後會透過通知告知(駁回時也會附上理由)。

## 審查(給管理員)

- 從控制台的「匯入申請」或「工具」選單開啟審查畫面。有新申請時會收到通知,管理畫面中也會顯示「有待審查的匯入申請。」
- 開啟申請後,可以確認檔案開頭的行(最多 100 行,可在框內捲動)・總數・依帳號所在伺服器統計的數量。
- 用「核准並匯入」核准後會開始匯入,用「駁回」可以填寫理由拒絕。核准・駁回會記錄在管理日誌中。

::: warning
如果在核准時檔案已被刪除,或申請者已被凍結・刪除・遷移,或不再擁有可以匯入的角色,則不會執行匯入,申請會保持待審查狀態(仍可駁回)。
:::

## 給開發者

- 新增了 `admin/import-requests/{list,show,approve,reject}`・`import-requests/{list,cancel}`。
- `i/import-*` 會透過 `requiresApproval` 回傳是否作為申請處理。
- `juice/public-settings`・`admin/juice/settings` 中有 `importApprovalRequiredTypes`。
