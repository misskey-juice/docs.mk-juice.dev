# 塗鴉

一個人畫畫的功能。可以使用與[繪畫聊天](./draw-room.md)相同的工具(筆・橡皮擦・填色・圖形・圖層等)繪畫。可以從導覽列的「塗鴉」開啟(`/doodle`)。

## 繪畫

- 從「新塗鴉」開始繪畫。之前畫的塗鴉可以從「繼續畫」清單中開啟。清單中會顯示縮圖・畫布大小・更新時間。
- 名稱和畫布大小在繪畫途中也可以從「塗鴉設定」中變更。大小上限為 3840px(與角色無關)。
- 工具的用法與繪畫聊天相同。詳情請參閱[繪畫聊天的「繪畫」](./draw-room.md#繪畫)。
- 因為是一個人畫,清除・刪除圖層也可以復原。沒有聊天・參與者・分享・撫摸。
- 塗鴉可以從清單中刪除(也會從此瀏覽器中消失,且無法還原)。

## 縮時回放

透過畫面右上角的「縮時回放」(▷),可以依序回放畫過的線條。

- 長度可以在 10〜60 秒之間選擇。
- 使用「產生影片」,可以將回放內容產生影片(WebM。無法錄製的瀏覽器為 mp4),並下載・儲存到雲端硬碟・發布為貼文。在無法產生影片的瀏覽器中,只能回放。
- 除了繪製線條,還會追蹤圖層的顯示・隱藏・濃度・混合模式・排序,以及繪製線條以外的操作(用範圍・套索移動、旋轉、縮放、翻轉、刪除、復原、重做等)並回放。在操作處會先短暫顯示變化後的畫面,再繼續(復原的線條也會在畫出後消失)。
- 此追蹤只針對 2026.10.0-juice+4.4 之後的操作。之前的操作因為沒有記錄,不會追蹤。
- 可以疊加與上傳圖片相同的浮水印預設。可以在縮時回放畫面中選擇・編輯・新增預設。
- 像素畫這類小畫布會不模糊地依整數倍放大輸出。
- 產生影片期間,請保持分頁處於顯示狀態(分頁被隱藏時會暫停,返回後繼續產生)。

## 裁切・擴展畫布

透過畫面右上角的「裁切畫布」,可以用與裁切圖片相同的操作變更畫布範圍。

- 拖曳邊框或控制點來決定範圍。將邊框向外拖曳可以擴展畫布。
- 也可以用數字指定寬度・高度・位置(X・Y)。
- 按 `Enter` 套用,按 `Esc` 取消。
- 邊框外的線條不會被刪除,重新擴展後會再次顯示。
- 也可以從範圍工具選取的範圍・選取範圍列・圖片選單開始裁切。
- 套用後,復原・重做的歷史記錄會被清除。

## 儲存方式

- 畫好的畫會依帳號自動儲存在此瀏覽器中,不會傳送到伺服器。
- 因此,無法在其他瀏覽器或裝置上繼續畫。清除瀏覽器資料後,塗鴉也會消失。
- 只有在以圖片形式儲存到雲端硬碟或發布為貼文時,該圖片才會傳送到伺服器。方法與繪畫聊天的[儲存・發布為圖片](./draw-room.md#儲存・發布為圖片)相同。

## 從發文表單繪畫

- 透過發文表單的塗鴉按鈕,可以畫新的塗鴉,或繼續畫之前的塗鴉(在視窗中開啟)。
- 使用「附加到貼文」,可以將畫好的畫直接附加到該表單。

## 導覽列

「塗鴉」已包含在導覽列的預設排列中。對之前就在使用的人也只會加入一次(自己移除後不會再次加入)。
