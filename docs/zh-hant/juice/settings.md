# JUICE 獨有功能設定

Juice Server 擁有多個標準 Misskey 中沒有的獨有功能。這些獨有功能的相關設定都集中在控制面板的「**JUICE**」項目中,並整理為「帳號」「時間軸・顯示」「申請表單」三個分類。

## 可設定的主要項目

使用管理員帳號登入後,進入控制面板 → 「JUICE」,即可變更以下獨有功能的啟用・停用及各項選項:

- [第三方登入](./social-login.md)中各服務商(Discord・Google・GitHub・GitLab・Microsoft)的啟用・停用,用戶端 ID・用戶端密鑰,以及共用的重新導向 URI
- [審核制註冊](./approval-signup.md)的啟用・停用,註冊理由的必填/選填・最大字數
- 將建立時間未超過指定時長的帳戶發起的追蹤,無論目標使用者是否啟用審核制追蹤都作為需要審核的追蹤請求處理這項功能的啟用・停用,及時長閾值
- [使用者排行榜](./user-ranking.md)的統計週期・顯示人數
- [中繼時間軸](./relay-timeline.md)的啟用・停用
- [媒體時間軸](./media-timeline.md)的啟用・停用
- [MIDI 播放器](./midi-player.md)允許播放的最大檔案大小(預設 500KB)、鋼琴卷簾視覺化的啟用狀態・卷簾速度・最大同時發聲數
- [表情符號申請](./emoji-request.md)・頭像裝飾申請的啟用・停用,同時申請數量上限,每日申請次數上限,必填項目(分類・標籤・授權・說明)設定
- [LaTeX(數學公式)顯示](./latex.md)的啟用・停用
- [聯絡表單](./contact-form.md)的啟用・停用、分類管理、內文最大字數
- [繪畫聊天](./draw-room.md)的啟用・停用、單一房間的線條資料量上限
- 顯示 Misskey 系伺服器(Misskey・CherryPick・Sharkey)使用者的頭像裝飾(預設啟用)
- [檢舉](./abuse-report.md)分類管理
- 在新註冊和變更電子郵件地址時,不接受帶 +標籤(`name+tag@…`)的電子郵件地址和含句點的 Gmail 地址(`na.me@gmail.com`)(預設為停用。+標籤與 Gmail 句點可以分別單獨開關。無論是否已有對應帳號都會適用,註冊畫面會顯示不接受的原因。聯絡表單不受影響)
- 禁止使用拋棄式電子郵件地址的設定(預設停用)。在註冊・變更電子郵件地址・聯絡表單(回覆方式為電子郵件時)中,不接受網域及其子網域在 [disposable-email-domains](https://github.com/disposable-email-domains/disposable-email-domains) 清單中的地址。與「電子郵件地址驗證」的方式無關。清單每天重新取得一次,取得失敗時繼續使用先前的清單(一次都未取得之前,不會用該清單判定)。管理畫面會顯示目前清單的數量和取得時間。被誤列入的網域,在「不視為拋棄式的網域」中每行填寫一個即可接受
- 歡迎頁面・「新增帳戶」選單中「使用邀請碼註冊」按鈕、「探索其他伺服器」按鈕的顯示・隱藏
- 啟動載入畫面顯示的自訂啟動語

個人設定([小工具位置](./widget-position.md)、時間軸分頁列中顯示哪些時間軸及其順序、包含裝飾性 MFM 的貼文自動僅本機化、MFM 搜尋框使用的搜尋引擎、放在貼文「+」旁邊的收藏・表情回應按鈕、不轉換貓貼文文字的設定、[附加小說 txt 時預設不允許下載](./novel.md#不允許下載附加的-txt)的設定等)與此不同,需在 `/settings/juice` 中另行變更。

各功能的詳細內容,請參閱相應頁面。
