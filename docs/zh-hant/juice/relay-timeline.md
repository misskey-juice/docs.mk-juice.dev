# 中繼時間軸

僅顯示透過已註冊中繼伺服器接收到的貼文的專用時間軸。

## 顯示範圍

- 僅顯示透過中繼接收到的、公開範圍為「公開」的貼文。僅追蹤者可見或私訊等內容不在顯示範圍內。
- 新增中繼之前接收到的貼文不會顯示。

## 使用方法

在時間軸切換選項中選擇「中繼」即可查看。與其他時間軸相同,新貼文會即時顯示。

每則貼文都會顯示是透過哪個中繼(主機名稱)送達的。

## 在Deck中使用

在Deck UI中新增或編輯「時間軸」欄位時,類型選擇中也可以選擇中繼時間軸。每個欄位可以個別設定要篩選的中繼。

## 對未登入使用者的顯示

是否向未登入的使用者顯示,取決於控制臺「審查」中的「使用者建立的內容對訪客的公開範圍」設定。由於經由中繼送達的貼文全部是遠端貼文,僅在設定為「全部公開」時才會顯示;設定為「僅公開本地內容,遠端內容則不公開」或「全部不公開」時,不會顯示任何內容。
