# 自訂表情符號・頭像裝飾指南

申請自訂表情符號或頭像裝飾時,請遵守以下指南。請同時參閱[規則](./rules.md)・[服務條款](./tos.md)。

## 共同注意事項

- 如果使用需要標註來源的素材(例如免費素材網站要求必須標示出處),請在「授權」欄中準確填寫出處、作者名及授權類型。如果是自己製作的內容,或素材本身無需標註,則不必勉強填寫。
- 未經授權使用真實企業、團體標誌或商標的申請將被駁回。不過,若該標誌圖片明確標註了允許使用的授權(例如企業官方發布的素材),只需在「授權」欄中註明企業官方網址及圖片的授權即可提交申請。
- 包含 NSFW、暴力性或歧視性內容的圖片不得申請。適用與[規則](./rules.md)相同的標準。
- 用於重現違反公序良俗的表現等超出預期用途的申請,同樣屬於駁回對象。
- 如果判斷上有疑慮,審核時可能會另外與您確認。不必想得太複雜,歡迎輕鬆申請。

## 自訂表情符號

- 請使名稱・分類易於理解,避免與其他表情符號混淆。
- 建議圖片解析度縱橫不超過 512px。
- 申請將保持待審核狀態,直至被核准或駁回。若被駁回,將通知駁回理由。如需再次申請,請以新申請的形式重新提交。
- 詳細申請方法請參閱[表情符號申請](../juice/emoji-request.md)。

### 從其他實例引入表情符號

Misskey 有一種文化: 將其他實例上使用的表情符號下載下來,匯入到自己的實例中。在本實例上,如果您想直接使用其他實例的表情符號,同樣歡迎申請。

- 如果來源處標明了授權,請按照該授權填寫在「授權」欄中。
- 如果來源處也沒有任何授權資訊,只需在「授權」欄中填寫取得來源的實例名稱即可。不必因為不清楚確切的授權而放棄申請。
- 但是,如果原作者明確表示「請勿轉載・再散布」,或該表情符號明顯存在問題(例如真實企業的商標或標誌),請不要申請。

### 關於包含文字的表情符號與字型

若表情符號中包含文字,請注意所使用字型的授權。相較於「是否付費」,更重要的是**該字型是否允許商業使用**。許多免費字型存在「禁止商用」、「禁止加工・再散布」等限制,反之,付費字型是否允許商用也因產品而異。

- 請自行確認授權不存在問題後再提交申請。
- 如果拿不準,或審核時可能需要核實,建議在「授權」欄中註明所用字型名稱、取得方式及授權參考連結,以便更放心。
- 如果是手寫或使用向量工具自行繪製文字(未使用字型),請註明這一點,將有助於審核更順利地進行。

## 頭像裝飾

- 使用與自訂表情符號相同的申請機制,需輸入圖片・名稱・分類・授權進行申請。
- 由於該裝飾會疊加顯示在個人頭像上,請設計為透明背景等適合疊加在頭像上的樣式。
- 建議圖片解析度縱橫不超過 512px。

## 關於審核

申請的核准・駁回由管理員或經角色授權審核權限的使用者執行。不符合上述指南的申請可能會被駁回。

## 常見問題

### 自己畫的表情符號,「授權」欄應該填什麼?

請填寫自己的 Misskey ID(例如 `@c30`)。使用了素材時,請填寫素材來源和授權名稱(如 CC BY-SA 4.0)。

### 可以引入其他伺服器的表情符號嗎?不知道授權時怎麼辦?

可以申請。來源註明了授權時請遵守;什麼都沒寫時,在「授權」欄填寫來源伺服器的名稱即可。但請不要申請作者明確表示「請勿轉載」的表情符號,或企業標誌等明顯有問題的表情符號。

### 含文字的表情符號所用的字型,需要注意什麼?

重要的不是「付費還是免費」,而是**該字型是否允許商用**。在「授權」欄寫上字型名稱和可以確認授權的 URL 會更放心。沒有使用字型而是自己造字時,請註明。

### 可以申請企業標誌嗎?

原則上會駁回。但如果是官方作為素材發布、且授權中明確允許使用的,只要在「授權」欄填寫企業的官方 URL 和圖片的授權即可。

### 最多可以申請多少件?

目前在 Juice Server 上,待審查的申請表情符號・頭像裝飾各最多 200 件,一天(最近 24 小時)內可送出的次數各最多 256 次(可能依角色而異)。一次最多可以合併申請 10 件。申請表單會顯示還能申請多少件・多少次。

### 圖片應該多大?

建議寬高均在 512px 以內。頭像裝飾會疊加顯示在大頭貼上,請採用透明背景等以疊加為前提的設計。

### 被駁回後會怎樣?

會透過通知收到駁回理由。如果想再次申請,請根據理由修改後,作為新的申請重新提出。

### 申請時使用的圖片會怎樣?

申請時可以選擇審查結束後是否刪除圖片。選擇刪除時,無論核准還是駁回,審查結束時都會刪除雲端硬碟中的檔案。核准時圖片會複製到表情符號,所以刪除也不會影響表情符號。

### 什麼時候應該開啟「敏感」和「僅限本地」?

- **敏感**: 對於看的人可能會介意的圖案等、接近[規則](./rules.md)中 NSFW 標準的內容,請開啟。敏感的表情符號不能作為回應加到設定為不接受敏感回應的貼文上。
- **僅限本地**: 只想在本伺服器內使用的表情符號請開啟。開啟後,表情符號的圖片不會傳送到其他伺服器(在其他伺服器上可能只顯示名稱)。

### 可以把版權角色的台詞做成表情符號嗎?

請不要使用從動畫或漫畫等的畫面・分鏡中**直接擷取的圖片**。用 [MEGAMOJI](https://zk-phi.github.io/MEGAMOJI/) 等工具把台詞做成文字表情符號是可以的。但請注意會劇透作品內容的台詞。

申請時,請依以下方式填寫。

- **分類**: `文字/版権/<作品名>`
  - 作品名如果有官方確定的簡稱,請使用該簡稱(例: Misskey Juice → `JUICE`、アイドルマスター(THE IDOLM@STER) → `アイマス`、僕のヒーローアカデミア(我的英雄學院) → `ヒロアカ`)。
- **標籤**: 作品名・說出台詞的角色名(建議)
  - 角色名請使用「平假名」。
  - 名字不是日語時(英文名等)也請用平假名書寫,有「・」的地方改為空格,分成不同的標籤(例: John Smith → `じょん すみす`)。

詳細的申請步驟請參閱[表情符號申請](../juice/emoji-request.md)・[頭像裝飾申請](../juice/avatar-decoration-request.md)。
