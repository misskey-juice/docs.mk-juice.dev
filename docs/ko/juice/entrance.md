# JUICE 입구 페이지

로그인하지 않은 사람에게 표시되는 환영 페이지(입구 페이지)의 모양에 JUICE 독자적인 "juice"를 추가했습니다.

## 전환 방법

관리자는 제어판 → 브랜딩의 "입구 페이지의 스타일"에서 "juice"를 고를 수 있습니다. 원래의 classic・simple과 전환할 수 있습니다.

## 표시되는 내용

서버 소개・가입 패널과 함께 다음 내용을 한눈에 볼 수 있습니다.

- 등록된 사용자・온라인・연결된 서버・노트의 수
- 로컬 타임라인
- 인기(트렌드 태그와 인기 게시물)
- 활동
- 연결된 서버의 일부

스마트폰 등 폭이 좁은 화면에서는 1열로 나열됩니다.

## 설정에 맞춘 표시

- "액티비티 표시하기"・"타임라인 표시"(방문자용 설정)를 꺼 두면 그 부분은 표시하지 않습니다.
- 로컬 타임라인을 쓸 수 없는 설정일 때나 연합하지 않는 설정일 때도 그에 맞춰 표시를 바꿉니다.

## 배경 이미지

배경 이미지 URL이 설정되어 있으면 페이지 전체에 배경 이미지를 깔고 패널을 반투명하게 합니다. 타임라인・인기 안의 노트도 비쳐 보이게 표시됩니다(긴 노트를 접었을 때의 페이드나 "더 보기"는 그대로입니다).

## 로그인하지 않았을 때의 다른 화면

입구 페이지가 "juice"일 때는, 로그인하지 않은 사람이 보는 다른 화면(노트・서버 정보・그림 채팅 방 등)도 같은 모양이 됩니다.

- 배경 이미지 URL이 설정되어 있으면 이미지를 전체에 깔고, 페이지 내용 뒤를 흐리게 해서 패널을 반투명하게 합니다. 배경 이미지가 없을 때는 위쪽에만 강조 색을 옅게 깝니다.
- 넓은 화면에서는 옆에 서버 소개・가입과, 등록된 사용자・온라인・연결된 서버・노트의 수를 표시합니다. 스마트폰에서는 위쪽 바(서버 이름과 가입 버튼)도 반투명이 됩니다.
- 그림 채팅 방에서는 캔버스 주위도 비쳐 보입니다. 주의 문구(CW)가 붙은 방에서 그림을 가리는 막은 비치지 않습니다.

## "가입 신청하기" 버튼

색이 들어간 "가입 신청하기" 버튼에 붙는 JUICE 배지를 버튼 글자 색으로 칠해서 보기 쉽게 했습니다. 이것은 모든 입구 페이지에 공통입니다.

## 개발자용

`admin/update-meta`의 `entrancePageStyle`에 `juice`를 지정할 수 있습니다.
