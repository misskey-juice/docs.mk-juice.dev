# 이모지 신청

일반 사용자가 커스텀 이모지 추가를 신청할 수 있는 기능입니다.

## 신청 방법

이모지 신청 페이지에서 아래 항목을 입력하여 신청합니다.

- 이모지 이미지
- 이름
- 카테고리
- 라이선스

카테고리・태그・라이선스 같은 항목은 관리자 설정에 따라 개별적으로 필수로 지정되어 있을 수 있습니다. 필수 항목에는 "(필수)"라고 표시되며, 미입력 상태에서는 신청 버튼이 비활성화됩니다. 여러 건을 한꺼번에 신청할 경우, 미입력 항목이 있는 카드의 헤더에 경고 배지가 표시됩니다.

신청은 반려 또는 승인될 때까지 보류 상태로 유지됩니다. 승인되면 바로 커스텀 이모지로 사용할 수 있게 됩니다. 반려된 경우 이유가 통지됩니다. 다시 신청하고 싶은 경우 새로운 신청으로 다시 제출해 주세요. 심사 대기 중이라면 신청자 본인이 신청을 취소할 수도 있습니다.

## 신청 전에 준비해 두면 좋은 항목

아래와 같은 내용을 미리 준비해 두면 양식 입력이 수월합니다.

```
이모지 이름:
카테고리:
태그(공백으로 구분):
라이선스(제작자명・이용 조건 등):
민감한 이미지에 해당하는지:
로컬 한정으로 할지:
```

- 이모지 이름에는 반각 영숫자와 `_`만 사용할 수 있습니다(예: `party_blob`). 이미지를 선택하면 파일명에서 자동으로 후보가 입력됩니다.
- 태그는 반각 공백뿐만 아니라 전각 공백 등의 공백으로도 구분할 수 있습니다(신청・심사・이모지 편집 칸 모두 같습니다).
- 이미지 해상도는 가로세로 512px까지를 권장합니다.
- 라이선스는 직접 제작한 경우 본인의 Misskey ID(예: `@c30`)를, 소재를 이용한 경우 배포처나 라이선스명(CC BY-SA 4.0 등)을 명시해 주세요. 다른 인스턴스의 이모지를 가져오는 경우의 작성법은 [가이드라인](../service/emoji-avatar-decoration-guidelines.md#다른-인스턴스의-이모지를-가져오는-경우)을 참고해 주세요.

## 신청 건수 제한

동시에 낼 수 있는 신청(심사 대기) 건수에는 제한이 있습니다(기본 3건). 또한 연속 신청을 방지하기 위한 레이트 리밋도 있습니다. 신청 폼에는 현재 심사 대기 건수・앞으로 몇 건 더 신청할 수 있는지・한 번에 모아서 신청할 수 있는 상한(최대 10건)이 표시됩니다.

심사 대기 건수 제한과는 별도로, 하루에 보낼 수 있는 신청 횟수에도 제한이 있습니다(기본 5회, 최근 24시간 슬라이딩 윈도우). 신청 폼에는 앞으로 몇 번 더 보낼 수 있는지・다음에 횟수가 회복되는 일시도 표시됩니다.1건씩 신청한 것과 한꺼번에 신청한 것은 합쳐서 셉니다.

## 신청 이미지의 취급

신청 시, 심사 완료 후 이미지를 삭제할지 여부를 선택할 수 있습니다. 체크한 경우, 승인・반려 어느 쪽이든 심사 완료 시 드라이브 파일이 삭제됩니다(승인 시에는 이모지 쪽에 이미지가 복사되므로 삭제해도 이모지 자체에는 영향이 없습니다).

## 심사 대기 중인 신청의 이미지 교체

심사를 기다리는 동안에는 신청한 사람이 신청의 이미지만 교체할 수 있습니다.

- 내 신청 목록에서 심사 대기 중인 신청의 "이미지 교체"를 눌러 새 이미지를 고릅니다(드라이브・PC・URL에서 고를 수 있습니다. PC에서 고를 때는 이미지 이외의 파일은 고를 수 없습니다).
- 교체하면 목록의 섬네일이 바로 새 이미지로 바뀝니다.
- "심사 완료 후 이미지 삭제"로 해 둔 신청에서는 더 이상 쓰이지 않는 이전 이미지를 삭제합니다(다른 신청에서 같은 이미지를 쓰고 있으면 삭제하지 않습니다).
- 이름이나 카테고리 등 이미지 이외의 내용은 바뀌지 않습니다. 이미 만들어진 이모지의 이미지를 바꾸고 싶을 때는 "교체 신청"을 사용해 주세요.

::: info 모더레이터용
심사 화면에서 보고 있던 이미지가 그 뒤에 신청자에 의해 교체되었다면, 승인・거부는 "이미지가 교체되었습니다"라고 표시되며 거절됩니다. 목록을 다시 불러와 지금의 이미지를 확인한 뒤 다시 심사해 주세요.
:::

## 심사(모더레이터용)

- 심사 화면에서 신청을 골라 한꺼번에 승인・반려할 수 있습니다. 한꺼번에 처리한 경우에도 신청자에 대한 알림・메일과 모더레이션 로그는 1건씩 남습니다.
- 신청자가 한 번의 전송으로 함께 낸 신청은, 모더레이터에게 가는 새 신청 알림과 System Webhook을 하나로 묶어 보냅니다(알림에는 "외 N건"이 붙습니다).

::: warning System Webhook을 받고 있는 경우
v3.19부터 `emojiRequestCreated`의 페이로드에 건수 `count`와 신청 목록 `requests`가 추가되었습니다. `id`・`name`・`category`는 첫 번째 신청의 것입니다. 신청 1건마다 Webhook이 온다는 전제로 처리하고 있었다면, `requests`를 보도록 변경해 주세요.
:::
