# 中继时间线

仅显示通过已注册中继服务器接收到的帖子的专用时间线。

## 显示范围

- 仅显示通过中继接收到的、公开范围为"公开"的帖子。仅关注者可见或私信等内容不在显示范围内。
- 添加中继之前接收到的帖子不会显示。

## 使用方法

在时间线切换选项中选择"中继"即可查看。与其他时间线相同,新帖子会实时显示。

每条帖子都会显示是通过哪个中继(主机名)送达的。

## 在Deck中使用

在Deck UI中添加或编辑"时间线"栏目时,类型选择中也可以选择中继时间线。每个栏目可以单独设置要筛选的中继。

## 对未登录用户的显示

是否向未登录的用户显示,取决于控制面板"管理"中的"用户生成内容对非用户的可见性"设置。由于经由中继送达的帖子全部是远程帖子,仅在设置为"全部公开"时才会显示;设置为"仅公开本地内容,隐藏远程内容"或"全部隐藏"时,不会显示任何内容。
