# BPM 测量小组件

可以测量节奏(BPM)的小组件。添加小组件时选择"BPM 测量"即可放置。

## 测量方式

- **点击测量**: 跟随节奏点击按钮,会根据最近 16 次的间隔计算出 BPM。
- **按时间线或通知的速度测量**: 将时间线(首页・本地・社交・全局・媒体・中继)或通知的到达速度(最近 1 分钟的条数)显示为 BPM。
- **用滑块设定**: 可以用滑块(对数)或输入数字在 1〜100000BPM 之间设定并播放。

## 节拍器

可以按测得的 BPM 播放节拍器。可以选择声音,并可在小组件中开关。

BPM 没有上限(声音最多每秒 100 拍)。改变速度后会立即以新速度播放,在未查看的标签页中也不会变慢。重新加载页面后,操作画面即可开始播放。
