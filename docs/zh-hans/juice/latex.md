# LaTeX(数学公式)显示

在帖子中编写 LaTeX 格式的数学公式后,会被实际渲染显示的功能。此功能是恢复了官方 Misskey 曾经拥有、在 Juice Server 上重新实现的功能。

## 书写方式

使用 MFM 的数学公式语法。

- 行内公式: 用 `\(` 和 `\)` 包裹
- 块级公式: 用 `\[` 和 `\]` 包裹(以居中的显示公式呈现,∫ 和 ∑ 会变大,上下标位于上下方)

## 注意事项

- 根据公式内容的不同,显示可能会失败,但这种情况不会导致页面损坏,仅相应部分不会显示。
- 此功能可能会在服务器整体设置中被禁用。禁用时,公式源代码将直接以代码形式显示。
