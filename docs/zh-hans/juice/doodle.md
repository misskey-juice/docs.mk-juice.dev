# 涂鸦

一个人画画的功能。可以使用与[绘画聊天](./draw-room.md)相同的工具(笔・橡皮擦・填充・图形・图层等)绘画。可以从导航栏的"涂鸦"打开(`/doodle`)。

## 绘画

- 从"新涂鸦"开始绘画。之前画的涂鸦可以从"继续画"列表中打开。列表中会显示缩略图・画布大小・更新时间。
- 名称和画布大小在绘画途中也可以从"涂鸦设置"中更改。大小上限为 3840px(与角色无关)。
- 工具的用法与绘画聊天相同。详情请参阅[绘画聊天的"绘画"](./draw-room.md#绘画)。
- 因为是一个人画,清除・删除图层也可以撤销。没有聊天・参与者・分享・抚摸。
- 涂鸦可以从列表中删除(也会从此浏览器中消失,且无法恢复)。

## 延时回放

通过画面右上角的"延时回放"(▷),可以按顺序回放画过的线条。

- 时长可以在 10〜60 秒之间选择。
- 使用"生成视频",可以将回放内容生成视频(WebM。无法录制的浏览器为 mp4),并下载・保存到网盘・发布为帖子。在无法生成视频的浏览器中,只能回放。
- 撤销的线条和移动前的线条位置不会回放。
- 生成视频期间,请保持标签页处于显示状态(标签页被隐藏时会暂停,返回后继续生成)。

## 裁剪・扩展画布

通过画面右上角的"裁剪画布",可以用与裁剪图片相同的操作更改画布范围。

- 拖动边框或控制点来决定范围。将边框向外拖动可以扩展画布。
- 也可以用数字指定宽度・高度・位置(X・Y)。
- 按 `Enter` 应用,按 `Esc` 取消。
- 边框外的线条不会被删除,重新扩展后会再次显示。
- 应用后,撤销・重做的历史记录会被清除。

## 保存方式

- 画好的画会按账户自动保存在此浏览器中,不会发送到服务器。
- 因此,无法在其他浏览器或设备上继续画。清除浏览器数据后,涂鸦也会消失。
- 只有在以图片形式保存到网盘或发布为帖子时,该图片才会发送到服务器。方法与绘画聊天的[保存・发布为图片](./draw-room.md#保存・发布为图片)相同。

## 从发帖表单绘画

- 通过发帖表单的涂鸦按钮,可以画新的涂鸦,或继续画之前的涂鸦(在窗口中打开)。
- 使用"添加到帖子",可以将画好的画直接附加到该表单。

## 导航栏

"涂鸦"已包含在导航栏的默认排列中。对之前就在使用的人也只会添加一次(自己移除后不会再次添加)。
