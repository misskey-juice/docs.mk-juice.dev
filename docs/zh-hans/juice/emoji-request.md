# 表情符号申请

允许普通用户申请添加自定义表情符号的功能。

## 申请方法

在表情符号申请页面填写以下内容进行申请:

- 表情符号图片
- 名称
- 分类
- 许可协议

分类・标签・许可协议等项目,可能已被管理员设置为个别必填。必填项目会标注"(必填)",未填写时申请按钮将无法点击。若一次性提交多个申请,存在未填写项目的卡片标题处会显示警告徽章。

申请将保持待审核状态,直至被驳回或批准。一经批准,即可立即作为自定义表情符号使用。若被驳回,将通知驳回理由。如需再次申请,请以新申请的形式重新提交。在待审核期间,申请者本人也可以取消申请。

## 申请前准备好这些内容会更顺利

预先准备好以下内容,填写申请表单时会更顺利。

```
表情符号名称:
分类:
标签(用空格分隔):
许可协议(作者名・使用条件等):
是否属于敏感图片:
是否仅限本地:
```

- 表情符号名称只能使用半角英数字和 `_`(例如 `party_blob`)。选择图片后,系统会根据文件名自动填入候选名称。
- 标签不仅可以用半角空格分隔,也可以用全角空格等空白分隔(申请・审核・表情符号编辑的栏位都一样)。
- 建议图片分辨率横竖不超过 512px。
- 许可协议方面,若为自制内容请填写您自己的 Misskey ID(如 `@c30`),若使用了素材,请注明来源及许可协议名称(如 CC BY-SA 4.0)。从其他实例引入表情符号时的填写方法请参阅[指南](../service/emoji-avatar-decoration-guidelines.md#从其他实例引入表情符号)。

## 申请数量限制

同时可提交的申请(待审核)数量有限制(默认为 3 个)。此外,为防止连续申请,还设有速率限制。申请表单会显示当前待审核数量、还能提交多少个申请,以及单次批量提交的上限(最多 10 个)。

除待审核数量限制外,每天可提交的申请次数也有上限(默认 5 次,按最近 24 小时的滑动窗口计算)。申请表单还会显示您还能提交几次,以及下次配额恢复的时间。

## 申请图片的处理

申请时,您可以选择审核完成后是否删除图片。若勾选此项,无论批准还是驳回,审核完成后云端硬盘文件都会被删除(批准时图片已被复制至表情符号,因此删除原图片不会影响表情符号本身)。

## 更换待审核申请的图片

在等待审核期间,申请者可以只更换申请的图片。

- 在自己的申请列表中,对待审核的申请点击"更换图片",选择新的图片(可以从网盘・电脑・URL 选择。从电脑选择时,不能选择图片以外的文件)。
- 更换后,列表中的缩略图会立即变为新图片。
- 如果申请设置了"审核完成后删除图片",会删除不再使用的旧图片(其他申请使用同一图片时不会删除)。
- 名称和分类等图片以外的内容不会改变。想要更改已经创建的表情符号的图片时,请使用"替换申请"。

::: info 面向版主
如果在审核画面中查看的图片之后被申请者更换,批准・驳回会显示"图片已被更换"并被拒绝。请重新加载列表,确认当前的图片后重新审核。
:::

## 审核(面向版主)

- 在审核画面中可以选中多个申请,一次性批准・驳回。即使一次性处理,给申请者的通知・邮件和管理日志也会按每个申请分别保留。
- 申请者通过一次提交一起发出的申请,会合并为一条发给版主的新申请通知和一个 System Webhook 发送(通知中会附上"及其他 N 件")。

::: warning 如果你在接收 System Webhook
从 v3.19 起,`emojiRequestCreated` 的负载中新增了件数 `count` 和申请列表 `requests`。`id`・`name`・`category` 为第一个申请的值。如果此前按照每个申请都会收到一次 Webhook 的前提进行处理,请改为读取 `requests`。
:::
