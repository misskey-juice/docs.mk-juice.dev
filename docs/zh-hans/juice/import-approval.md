# 导入审批

可以将从设置 → 账户数据进行的导入改为需要管理员批准的功能。需要批准的导入不会立即执行,而是成为申请,在管理员确认并批准后才会导入。

## 需要批准的导入

在控制面板的 JUICE 设置"导入审批"中选择需要批准的类型。默认只有关注,也可以选择静音・屏蔽・列表・天线。

## 审核者

可以审核的是版主,以及拥有角色策略"批准·驳回导入申请"的人。这些人自己的导入无需批准,会直接执行。

## 申请(面向用户)

- 需要批准的类型的导入按钮会变为"导入(需要批准)"。选择文件并导入后,会作为申请受理。
- 在设置 → 账户数据的"导入申请"中,可以查看自己申请的状态(待审核・已批准・已驳回・已撤回)以及被驳回时的理由。
- 待审核的申请可以通过"撤回"撤回。
- 同类型的申请仍在待审核时,无法提交新的申请。
- 申请被批准・驳回后会通过通知告知(驳回时也会附上理由)。

## 审核(面向管理员)

- 从控制面板的"导入申请"或"工具"菜单打开审核画面。有新申请时会收到通知,管理画面中也会显示"有待审核的导入申请。"
- 打开申请后,可以确认文件开头的行(最多 100 行,可在框内滚动)・总数・按账户所在服务器统计的数量。
- 用"批准并导入"批准后会开始导入,用"驳回"可以填写理由拒绝。批准・驳回会记录在管理日志中。

::: warning
如果在批准时文件已被删除,或申请者已被冻结・删除・迁移,或不再拥有可以导入的角色,则不会执行导入,申请会保持待审核状态(仍可驳回)。
:::

## 面向开发者

- 新增了 `admin/import-requests/{list,show,approve,reject}`・`import-requests/{list,cancel}`。
- `i/import-*` 会通过 `requiresApproval` 返回是否作为申请处理。
- `juice/public-settings`・`admin/juice/settings` 中有 `importApprovalRequiredTypes`。
