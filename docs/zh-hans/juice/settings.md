# JUICE 独有功能设置

Juice Server 拥有多个标准 Misskey 中没有的独有功能。这些独有功能的相关设置都集中在控制面板的「**JUICE**」项目中,并整理为「账号」「时间线・显示」「申请表单」三个分类。

## 可设置的主要项目

使用管理员账号登录后,进入控制面板 → "JUICE",即可更改以下独有功能的启用・禁用及各项选项:

- [第三方登录](./social-login.md)中各服务商(Discord・Google・GitHub・GitLab・Microsoft)的启用・禁用,客户端 ID・客户端密钥,以及通用的重定向 URI
- [审核制注册](./approval-signup.md)的启用・禁用,注册理由的必填/选填・最大字数
- 将创建时间未超过指定时长的账户发起的关注,无论目标用户是否启用审核制关注都作为需要审核的关注请求处理这一功能的启用・禁用,及时长阈值
- [用户排行榜](./user-ranking.md)的统计周期・显示人数
- [中继时间线](./relay-timeline.md)的启用・禁用
- [媒体时间线](./media-timeline.md)的启用・禁用
- [MIDI 播放器](./midi-player.md)允许播放的最大文件大小(默认 500KB)、钢琴卷帘可视化的启用状态・卷帘速度・最大同时发声数
- [表情符号申请](./emoji-request.md)・头像装饰申请的启用・禁用,同时申请数量上限,每日申请次数上限,必填项目(分类・标签・许可协议・说明)设置
- [LaTeX(数学公式)显示](./latex.md)的启用・禁用
- [联系表单](./contact-form.md)的启用・禁用、分类管理、正文最大字数
- [绘画聊天](./draw-room.md)的启用・禁用、单个房间的线条数据量上限
- 显示 Misskey 系服务器(Misskey・CherryPick・Sharkey)用户的头像装饰(默认启用)
- [举报](./abuse-report.md)分类管理
- 在新注册和更改邮箱地址时,不接受带 +标签(`name+tag@…`)的邮箱地址和含点号的 Gmail 地址(`na.me@gmail.com`)(默认禁用。+标签与 Gmail 点号可以分别单独开关。无论是否已有对应账号都会适用,注册画面会显示不接受的原因。联系表单不受影响)
- 欢迎页面・「添加账户」菜单中「使用邀请码注册」按钮、「探索其他服务器」按钮的显示・隐藏
- 启动加载画面显示的自定义启动语

个人设置([小组件位置](./widget-position.md)、时间线标签栏中显示哪些时间线及其顺序、包含装饰性 MFM 的帖子自动仅本地化、MFM 搜索框使用的搜索引擎、放在帖子"+"旁边的收藏・表情回应按钮、不转换猫帖子文字的设置、[附加小说 txt 时默认不允许下载](./novel.md#不允许下载附加的-txt)的设置等)与此不同,需在 `/settings/juice` 中单独更改。

各功能的详细内容,请参阅相应页面。
