# 自定义表情符号・头像装饰指南

申请自定义表情符号或头像装饰时,请遵守以下指南。请同时参阅[规则](./rules.md)・[服务条款](./tos.md)。

## 共同注意事项

- 如果使用需要署名的素材(例如免费素材网站要求必须标注来源),请在"许可协议"栏中准确填写出处、作者名及许可类型。如果是自己制作的内容,或素材本身无需标注,则不必勉强填写。
- 未经授权使用真实企业、团体标志或商标的申请将被驳回。不过,若该标志图片明确标注了允许使用的许可协议(例如企业官方发布的素材),只需在"许可协议"栏中注明企业官方网址及图片的许可协议即可提交申请。
- 包含 NSFW、暴力性或歧视性内容的图片不得申请。适用与[规则](./rules.md)相同的标准。
- 用于重现违反公序良俗的表现等超出预期用途的申请,同样属于驳回对象。
- 如果判断上有疑问,审核时可能会单独与您确认。不必想得太复杂,欢迎轻松申请。

## 自定义表情符号

- 请使名称・分类易于理解,避免与其他表情符号混淆。
- 建议图片分辨率横竖不超过 512px。
- 申请将保持待审核状态,直至被批准或驳回。若被驳回,将通知驳回理由。如需再次申请,请以新申请的形式重新提交。
- 详细申请方法请参阅[表情符号申请](../juice/emoji-request.md)。

### 从其他实例引入表情符号

Misskey 有一种文化: 将其他实例上使用的表情符号下载下来,导入到自己的实例中。在本实例上,如果您想直接使用其他实例的表情符号,同样欢迎申请。

- 如果来源处标明了许可协议,请按照该许可协议填写在"许可协议"栏中。
- 如果来源处也没有任何许可协议信息,只需在"许可协议"栏中填写获取来源的实例名称即可。不必因为不清楚确切的许可协议而放弃申请。
- 但是,如果原作者明确表示"请勿转载・再分发",或该表情符号明显存在问题(例如真实企业的商标或标志),请不要申请。

### 关于包含文字的表情符号与字体

若表情符号中包含文字,请注意所使用字体的许可协议。相比"是否付费",更重要的是**该字体是否允许商业使用**。许多免费字体存在"禁止商用"、"禁止加工・再分发"等限制,反之,付费字体是否允许商用也因产品而异。

- 请自行确认许可协议不存在问题后再提交申请。
- 如果拿不准,或审核时可能需要核实,建议在"许可协议"栏中注明所用字体名称、获取方式及许可协议参考链接,以便更放心。
- 如果是手写或使用向量工具自行绘制文字(未使用字体),请注明这一点,将有助于审核更顺利地进行。

## 头像装饰

- 使用与自定义表情符号相同的申请机制,需输入图片・名称・分类・许可协议进行申请。
- 由于该装饰会叠加显示在个人头像上,请设计为透明背景等适合叠加在头像上的样式。
- 建议图片分辨率横竖不超过 512px。

## 关于审核

申请的批准・驳回由管理员或经角色授权审核权限的用户执行。不符合上述指南的申请可能会被驳回。

## 常见问题

### 自己画的表情符号,"许可"栏应该填什么?

请填写自己的 Misskey ID(例如 `@c30`)。使用了素材时,请填写素材来源和许可名称(如 CC BY-SA 4.0)。

### 可以引入其他服务器的表情符号吗?不知道许可时怎么办?

可以申请。来源注明了许可时请遵守;什么都没写时,在"许可"栏填写来源服务器的名称即可。但请不要申请作者明确表示"请勿转载"的表情符号,或企业标志等明显有问题的表情符号。

### 含文字的表情符号所用的字体,需要注意什么?

重要的不是"收费还是免费",而是**该字体是否允许商用**。在"许可"栏写上字体名称和可以确认许可的 URL 会更放心。没有使用字体而是自己造字时,请注明。

### 可以申请企业标志吗?

原则上会驳回。但如果是官方作为素材发布、且许可中明确允许使用的,只要在"许可"栏填写企业的官方 URL 和图片的许可即可。

### 最多可以申请多少件?

目前在 Juice Server 上,待审核的申请表情符号・头像装饰各最多 200 件,一天(最近 24 小时)内可提交的次数各最多 256 次(可能因角色而异)。一次最多可以合并申请 10 件。申请表单会显示还能申请多少件・多少次。

### 图片应该多大?

建议宽高均在 512px 以内。头像装饰会叠加显示在头像上,请采用透明背景等以叠加为前提的设计。

### 被驳回后会怎样?

会通过通知收到驳回理由。如果想再次申请,请根据理由修改后,作为新的申请重新提交。

### 申请时使用的图片会怎样?

申请时可以选择审核结束后是否删除图片。选择删除时,无论批准还是驳回,审核结束时都会删除网盘中的文件。批准时图片会复制到表情符号,所以删除也不会影响表情符号。

### 什么时候应该开启"敏感"和"仅限本地"?

- **敏感**: 对于看的人可能会介意的图案等、接近[规则](./rules.md)中 NSFW 标准的内容,请开启。敏感的表情符号不能作为回应添加到设置为不接受敏感回应的帖子上。
- **仅限本地**: 只想在本服务器内使用的表情符号请开启。开启后,表情符号的图片不会发送到其他服务器(在其他服务器上可能只显示名称)。

### 可以把版权角色的台词做成表情符号吗?

请不要使用从动画或漫画等的画面・分镜中**直接截取的图片**。用 [MEGAMOJI](https://zk-phi.github.io/MEGAMOJI/) 等工具把台词做成文字表情符号是可以的。但请注意会剧透作品内容的台词。

申请时,请按以下方式填写。

- **分类**: `文字/版権/<作品名>`
  - 作品名如果有官方确定的简称,请使用该简称(例: Misskey Juice → `JUICE`、アイドルマスター(THE IDOLM@STER) → `アイマス`、僕のヒーローアカデミア(我的英雄学院) → `ヒロアカ`)。
- **标签**: 作品名・说出台词的角色名(推荐)
  - 角色名请使用"平假名"。
  - 名字不是日语时(英文名等)也请用平假名书写,有"・"的地方改为空格,分成不同的标签(例: John Smith → `じょん すみす`)。

详细的申请步骤请参阅[表情符号申请](../juice/emoji-request.md)・[头像装饰申请](../juice/avatar-decoration-request.md)。
