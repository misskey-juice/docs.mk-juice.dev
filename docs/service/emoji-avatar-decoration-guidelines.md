# カスタム絵文字・アバターデコレーションのガイドライン

カスタム絵文字やアバターデコレーションを申請する際は、以下のガイドラインを守ってください。[ルール](./rules.md)・[利用規約](./tos.md)とあわせてご確認ください。

## 共通の注意事項

- ライセンス表記が必要な素材(クレジット表記必須のフリー素材など)を使う場合は、「ライセンス」欄に出典・作者名・ライセンスの種類を正確に記載してください。自作のものや、ライセンス表記が不要な素材であれば、無理に記載しなくても大丈夫です。
- 実在の企業・団体のロゴや商標を無断で使用する申請は却下します。ただし、そのロゴ画像に利用を認めるライセンスが明記されている場合(公式に素材として配布されているものなど)は、企業の公式URLと画像のライセンスを「ライセンス」欄に記載していただければ問題ありません。
- NSFW・暴力的・差別的な内容を含む画像は申請できません。[ルール](./rules.md)の基準に準じます。
- 公序良俗に反する表現の再現など、想定される用途外での申請も却下対象です。
- 判断に迷う場合は、審査の際に個別に確認することがあります。あまり硬く考えず、気軽に申請してください。

## カスタム絵文字

- 名前・カテゴリは分かりやすく、他の絵文字と混同しにくいものにしてください。
- 画像の解像度は、縦横ともに512pxまでがおすすめです。
- 申請は承認または却下されるまで保持されます。却下された場合は理由が通知されます。もう一度申請したい場合は、新しい申請として出し直してください。
- 詳しい申請方法は[絵文字申請](../juice/emoji-request.md)をご覧ください。

### 他のインスタンスの絵文字を持ってくる場合

Misskeyには、他のインスタンスで使われている絵文字をダウンロードして自分のインスタンスに取り込む文化があります。当インスタンスでも、他のインスタンスの絵文字をそのまま使いたい場合に申請していただいて構いません。

- 取得元でライセンスが明記されている場合は、それに従って「ライセンス」欄に記載してください。
- 取得元にもライセンス情報が特に無い(何も書かれていない)場合は、「ライセンス」欄に取得元のインスタンス名を書いていただければ十分です。厳密なライセンスが分からないからといって申請を諦める必要はありません。
- 元の絵文字の作者が「無断転載・再配布しないでほしい」のように明言している場合や、実在の企業ロゴ・商標など明らかに問題がある絵文字は申請しないでください。

### 文字を含む絵文字とフォントについて

絵文字にテキストを含める場合、使用したフォントのライセンスにご注意ください。「有料か無料か」よりも、**そのフォントが商用利用を許可しているか**が重要です。フリーフォントの中には「商用利用不可」「加工・再配布不可」といった制限があるものも多く、逆に有料フォントでも商品によって商用利用の可否は異なります。

- ライセンス上問題がないことをご自身で確認したうえで申請してください。
- 判断に迷う場合や審査で確認が必要になった場合に備えて、「ライセンス」欄に使用したフォント名・入手方法・ライセンスの参照先URLを記載しておくと安心です。
- 手書きやベクターツールなどフォントを使わずに作字した場合は、その旨を記載してもらえると審査がスムーズです。

## アバターデコレーション

- カスタム絵文字と同じ申請の仕組みで、画像・名前・カテゴリ・ライセンスを入力して申請します。
- プロフィールアイコンに重ねて表示されるものなので、透過背景の画像など、アイコンに重ねることを前提としたデザインにしてください。
- 画像の解像度は、縦横ともに512pxまでがおすすめです。

## 承認について

申請の承認・却下は、管理者またはロールで承認権限を委譲されたユーザーが行います。上記のガイドラインに沿わない申請は却下されることがあります。

## よくある質問

### 自分で描いた絵文字の「ライセンス」欄には、何を書けばいいですか?

自分のMisskeyのID(例: `@c30`)を書いてください。素材を使った場合は、配布元やライセンスの名前(CC BY-SA 4.0 など)を書いてください。

### ほかのサーバーの絵文字を持ってきてもいいですか?ライセンスが分からないときは?

申請して大丈夫です。取得元にライセンスが書かれていればそれに従い、何も書かれていなければ「ライセンス」欄に取得元のサーバーの名前を書けば十分です。ただし、作者が「転載しないでほしい」と言っているものや、企業のロゴなど明らかに問題があるものは申請しないでください。

### 文字入りの絵文字に使ったフォントは、何に気をつければいいですか?

大事なのは「有料か無料か」ではなく、**そのフォントを商用で使ってよいか**です。「ライセンス」欄に、フォントの名前と、ライセンスを確かめられるURLを書いておくと安心です。フォントを使わずに作字した場合は、その旨を書いてください。

### 企業のロゴは申請できますか?

原則として却下します。ただし、公式に素材として配られていて、使ってよいことがライセンスで明記されている場合は、企業の公式URLと画像のライセンスを「ライセンス」欄に書いていただければ大丈夫です。

### 何件まで申請できますか?

今のJuice Serverでは、審査待ちの申請は絵文字・アバターデコレーションそれぞれ200件まで、1日(直近24時間)に送れる回数はそれぞれ256回までです(ロールによって変わることがあります)。1回にまとめて申請できるのは最大10件です。申請フォームに、あと何件・何回申請できるかが表示されます。

### 画像はどれくらいの大きさにすればいいですか?

縦横ともに512pxまでがおすすめです。アバターデコレーションはアイコンに重ねて表示されるので、背景を透明にするなど、重ねることを前提にしたデザインにしてください。

### 却下されたらどうなりますか?

却下の理由が通知で届きます。もう一度申請したい場合は、理由を踏まえて直したうえで、新しい申請として出し直してください。

### 申請に使った画像はどうなりますか?

申請するときに、審査が終わったら画像を削除するかどうかを選べます。削除を選んだ場合、承認・却下のどちらでも、審査が終わったときにドライブのファイルが削除されます。承認された場合は絵文字のほうに画像がコピーされるので、削除しても絵文字には影響ありません。

### 「センシティブ」と「ローカル限定」は、いつオンにすればいいですか?

- **センシティブ**: 見る人を選ぶ絵柄など、[ルール](./rules.md)のNSFWの基準に近いものはオンにしてください。センシティブな絵文字は、センシティブなリアクションを受け付けない設定のノートには、リアクションとして付けられません。
- **ローカル限定**: このサーバーの中だけで使いたい絵文字はオンにしてください。オンにすると、絵文字の画像がほかのサーバーに配られなくなります(ほかのサーバーからは、名前だけに見えることがあります)。

### 版権キャラのセリフを絵文字にしてもいいですか?

アニメや漫画などの画面・コマを**直接切り抜いた画像**はやめてください。[MEGAMOJI](https://zk-phi.github.io/MEGAMOJI/)などでセリフを文字の絵文字にするのは大丈夫です。ただし、作品のネタバレになるセリフには注意してください。

申請するときは、次のように書いてください。

- **カテゴリ**: `文字/版権/<作品名>`
  - 作品名は、公式で略称が決まっている場合はその略称にしてください(例: Misskey Juice → `JUICE`、アイドルマスター(THE IDOLM@STER) → `アイマス`、僕のヒーローアカデミア → `ヒロアカ`)。
- **タグ**: 作品名・セリフを言ったキャラクター名(推奨)
  - キャラクター名は「ひらがな」でお願いします。
  - 名前が日本語ではない場合(英語名など)もひらがなで書き、「・」があるところは空白にして、別々のタグに分けてください(例: John Smith → `じょん すみす`)。

詳しい申請の手順は、[絵文字申請](../juice/emoji-request.md)・[アバターデコレーション申請](../juice/avatar-decoration-request.md)をご覧ください。
