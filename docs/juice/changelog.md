# 更新履歴

misskey-juiceのJUICE独自機能に関する主な変更履歴です。本家Misskey由来の変更は含みません。全履歴は[GitHubのリリースページ](https://github.com/misskey-juice/misskey-juice/releases)をご覧ください。

## v2026.10.0-juice+4.6

- ウェルカムページの見た目に「juice」を追加([JUICEのエントランス](./entrance.md))。コントロールパネルのブランディングで、本家のclassic・simpleと切り替えられる。サーバーの紹介・登録と並べて、ユーザー・オンライン・つながっているサーバー・ノートの数、ローカルタイムライン、人気、アクティビティ、つながっているサーバーの一部を一覧できる。背景画像のURLが設定されていれば、ページ全体に敷いてパネルを半透明にする
- [連合の診断](./federation-diagnosis.md)の「署名付きでのユーザー情報の取得」に、署名の鍵の種類を出すように(RSA(鍵の長さ)・Ed25519・ECDSAを見分ける)。「inbox(配送先)の応答」を署名の無い空のPOSTで確かめるようにし、inboxが無い(404など)ときも問題なしになっていたのを修正
- ウェルカムページの色の付いた「参加を申請する」ボタンの上のJUICEバッジを、塗りつぶして見やすく
- 開発者向け: `admin/federation/diagnose-instance`の各項目に`keys`を追加し、inboxが配送を受け付けていないときは`inboxNotFound`を返すように。`admin/update-meta`の`entrancePageStyle`に`juice`を追加

## v2026.10.0-juice+4.5

- 設定 → アカウントのデータのインポートを、運営の承認式にできるように([インポートの承認](./import-approval.md))。JUICE設定で選んだ種類(既定はフォローだけ。ミュート・ブロック・リスト・アンテナも選べる)のインポートは申請になり、運営が承認したらインポートする。自分の申請の状態・却下の理由を見られ、審査待ちは取り下げられる
- インポートの申請の審査画面を追加。コントロールパネルと「ツール」メニューから開け、ファイルの先頭の行・全件数・サーバーごとの件数を見て承認・却下(理由つき)する。審査できるのはモデレーターと、新しいロールポリシー「インポートの申請の承認・却下」を持つ人
- [絵チャ](./draw-room.md)の部屋に説明を書けるように(10行・512文字まで)。部屋の一覧で名前の下に出て、部屋の中では「部屋の説明」のボタンで見られる
- 開発者向け: `admin/import-requests/{list,show,approve,reject}`・`import-requests/{list,cancel}`を追加。`i/import-*`が`requiresApproval`を返すように。`juice/public-settings`・`admin/juice/settings`に`importApprovalRequiredTypes`、`draw-rooms/create`・`update`に`description`を追加

## v2026.10.0-juice+4.4

- 連合しているサーバーの情報(`/instance-info/<host>`)に「診断」タブを追加(モデレーター向け)。このサーバーの設定・状態と、相手のサーバーへの実際の問い合わせを順に調べ、どこで連合が止まっているかを出す(相手には何も配送しない)。詳しくは[連合の診断](./federation-diagnosis.md)
- [落書き](./doodle.md)のタイムラプスで、レイヤーの見え方の変更や、線を描く以外の操作(移動・回転・拡大縮小・反転・削除・取り消し・やり直しなど)も追うように(この更新より前の操作は追わない)。ウォーターマークのプリセットを重ねられるように。キャンバスの切り抜きを、範囲ツールで選んだ範囲・選択範囲のバー・画像のメニューからも始められるように
- [絵チャ](./draw-room.md)と落書きのキャンバスの大きさに、ドット絵向けの32×32・64×64・128×128を追加し、大きさの下限を16に。描く人として参加していた部屋に入り直したときは、見学中から始めるように
- [アンテナ](./antenna.md)の受信ソースで「フォローしているユーザーのノート」を選べるように
- [ほかのサーバーの絵文字でのリアクション](./reaction-enhancements.md)の枠を点線にして、このサーバーの絵文字と見分けられるように。相乗りしたときに読み込み直すまで反映されない問題を修正
- 小説ビューワーの縦書きで、横幅によって左側の文字が見切れる問題を修正。ウォーターマークの二次元コードで、真ん中のアバターを読み込めないと読み込み中のまま止まる問題を修正
- 開発者向け: `admin/federation/diagnose-instance`を追加(`write:admin:federation`)。`draw-rooms/create`の`canvasPreset`に`pixel32`・`pixel64`・`pixel128`を追加し、`canvasWidth`・`canvasHeight`の下限を16に
