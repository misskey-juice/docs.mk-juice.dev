# JUICE独自機能の設定

Juice Serverには、標準のMisskeyには無い独自機能がいくつかあります。これらの独自機能に関する設定は、コントロールパネルの「**JUICE**」項目にまとめられています。「アカウント」「タイムライン・表示」「申請フォーム」の3カテゴリに整理されています。

## 設定できる主な項目

管理者アカウントでログインし、コントロールパネル → 「JUICE」から、以下のような独自機能の有効・無効や各種オプションを変更できます。

- [連携ログイン](./social-login.md)の各プロバイダー(Discord・Google・GitHub・GitLab・Microsoft)ごとの有効・無効、クライアントID・クライアントシークレット、共通のリダイレクトURI
- [承認式新規登録](./approval-signup.md)の有効・無効、登録理由の必須/任意・最大文字数
- 作成から一定時間が経過していないアカウントからのフォローを、フォロー先の承認制フォロー設定に関わらず承認が必要なフォローリクエストとして扱う機能の有効・無効、しきい値
- [ユーザーランキング](./user-ranking.md)の集計期間・表示人数
- [リレータイムライン](./relay-timeline.md)の有効・無効
- [メディアタイムライン](./media-timeline.md)の有効・無効
- [MIDIプレイヤー](./midi-player.md)で再生を許可する最大ファイルサイズ(既定500KB)、ピアノロールビジュアライザーの有効/無効・ロール速度・最大同時発音数
- [絵文字申請](./emoji-request.md)・アバターデコレーション申請の有効・無効、同時申請数の上限、1日あたりの送信回数上限、必須項目(カテゴリ・タグ・ライセンス・説明)の設定
- [LaTeX(数式)表示](./latex.md)の有効・無効
- [お問い合わせフォーム](./contact-form.md)の有効・無効、カテゴリ管理、本文の最大文字数
- [絵チャ](./draw-room.md)の有効・無効、1つの部屋の線のデータ量の上限
- Misskey系のサーバー(Misskey・CherryPick・Sharkey)のユーザーのアバターデコレーションの表示(既定は有効)
- [通報](./abuse-report.md)のカテゴリ管理
- +タグ付き(`name+tag@…`)・ドット入りのGmail(`na.me@gmail.com`)のメールアドレスを、新規登録とメールアドレスの変更で受け付けない設定(既定は無効。+タグとGmailのドットは個別にON/OFFできます。既存のアカウントの有無に関係なく適用され、登録画面には受け付けない理由が表示されます。お問い合わせフォームは対象外です)
- 使い捨てメールアドレスを使えないようにする設定(既定は無効)。[disposable-email-domains](https://github.com/disposable-email-domains/disposable-email-domains)の一覧に載っているドメインとそのサブドメインのアドレスを、新規登録・メールアドレスの変更・お問い合わせフォーム(返信方法がメールのとき)で受け付けません。「メールアドレスの検証」の方式に関係なく動きます。一覧は1日に1回取り直し、取れなかったときは前の一覧を使い続けます(一度も取得できていない間は、この一覧での判定はしません)。管理画面には、今の一覧の件数と取得した日時が表示されます。誤って一覧に載っているドメインは、「使い捨てと判定しないドメイン」に1行に1つずつ入れると受け付けるようになります
- ウェルカムページ・「アカウントを追加」メニューの「招待コードで登録」ボタン、「他のサーバーを探す」ボタンの表示・非表示
- 起動時のロード画面に表示するカスタムスプラッシュテキスト

個人ごとの設定([ウィジェット表示位置](./widget-position.md)、タイムラインのタブバーに表示するタイムラインの選択・並び替え、装飾的なMFMを含む投稿の自動ローカル化、MFMの検索窓で使う検索エンジン、ノートの「+」の横に置くお気に入り・リアクションのボタン、ネコの投稿の文字を置き換えない設定、[小説のtxtを初めからダウンロードさせない](./novel.md#添付したtxtをダウンロードさせない)設定など)は、こちらとは別に `/settings/juice` から変更します。

各機能の詳しい内容は、それぞれのページをご覧ください。
