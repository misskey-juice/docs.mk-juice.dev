# BPM計測ウィジェット

テンポ(BPM)を測れるウィジェットです。ウィジェットの追加から「BPM計測」を選んで置けます。

## 測り方

- **タップで測る**: リズムに合わせてボタンを押すと、直近16回の間隔からBPMを出します。
- **タイムラインや通知の速さで測る**: タイムライン(ホーム・ローカル・ソーシャル・グローバル・メディア・リレー)や通知に届く速さ(直近1分の件数)を、BPMとして表示します。
- **スライダーで決める**: 1〜100000BPMを、スライダー(対数)か数の入力で決めて鳴らせます。

## メトロノーム

測ったBPMで、メトロノームを鳴らせます。音の種類を選べ、ウィジェットからオン/オフを切り替えられます。

BPMの上限はありません(音は1秒に100拍まで)。速さを変えるとすぐに新しい速さで鳴り、見ていないタブでも遅くなりません。ページを再読み込みしたあとは、画面を操作すると鳴り始めます。
