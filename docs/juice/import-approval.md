# インポートの承認

設定 → アカウントのデータからのインポートを、運営の承認式にできる機能です。承認が要る種類のインポートは、すぐには行われずに申請になり、運営が確認して承認したあとにインポートされます。

## 対象になるインポート

コントロールパネルのJUICE設定「インポートの承認」で、承認が要る種類を選びます。既定ではフォローだけが対象で、ミュート・ブロック・リスト・アンテナも選べます。

## 審査する人

審査できるのは、モデレーターと、ロールポリシー「インポートの申請の承認・却下」を持つ人です。この人たち自身のインポートは、承認なしでそのまま行われます。

## 申請する(利用者向け)

- 承認が要る種類のインポートのボタンは、「インポート(承認が必要)」になります。ファイルを選んでインポートすると、申請として受け付けられます。
- 設定 → アカウントのデータの「インポートの申請」で、自分の申請の状態(審査待ち・承認済み・却下・取り下げ)と、却下されたときの理由を見られます。
- 審査待ちの申請は、「取り下げる」で取り下げられます。
- 同じ種類の申請が審査待ちのままだと、新しい申請はできません。
- 承認・却下されると、通知でお知らせします(却下のときは理由も届きます)。

## 審査する(運営向け)

- コントロールパネルの「インポートの申請」、または「ツール」メニューから審査画面を開きます。新しい申請が届くと通知が届き、管理画面にも「審査待ちのインポートの申請があります」と表示されます。
- 申請を開くと、ファイルの先頭の行(最大100行、枠の中でスクロールできます)・全件数・アカウントのサーバーごとの件数を確認できます。
- 「承認してインポートする」で承認するとインポートが始まり、「却下」では理由を書いて断ります。承認・却下は、モデレーションログに記録されます。

::: warning
承認しようとしたときに、ファイルが削除されていたり、申請した人が凍結・削除・引っ越しされていたり、インポートできるロールでなくなっていたりすると、インポートは行われず、申請は審査待ちのまま残ります(却下はできます)。
:::

## 開発者向け

- `admin/import-requests/{list,show,approve,reject}`・`import-requests/{list,cancel}`を追加しました。
- `i/import-*`は、申請にしたかどうかを`requiresApproval`で返します。
- `juice/public-settings`・`admin/juice/settings`に`importApprovalRequiredTypes`があります。
