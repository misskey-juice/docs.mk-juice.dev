# 落書き

1人で絵を描ける機能です。[絵チャ](./draw-room.md)と同じ道具(ペン・消しゴム・塗りつぶし・図形・レイヤーなど)で描けます。ナビゲーションバーの「落書き」から開けます(`/doodle`)。

## 描く

- 「新しい落書き」から描き始めます。前に描いた落書きは「続きを描く」の一覧から開けます。一覧には、小さな絵・キャンバスの大きさ・更新日時が表示されます。
- 名前とキャンバスの大きさは、描いている途中でも「落書きの設定」から変えられます。大きさの上限は3840pxです(ロールには関係ありません)。
- 道具の使い方は絵チャと同じです。詳しくは[絵チャの「描く」](./draw-room.md#描く)を見てください。
- 1人で描くので、レイヤーの消去・削除も取り消せます。チャット・参加者・共有・なでるはありません。
- 落書きは、一覧から削除できます(このブラウザからも消え、元に戻せません)。

## 保存のされ方

- 描いた絵は、このブラウザにアカウントごとに自動で保存されます。サーバーには送られません。
- そのため、別のブラウザや端末からは続きを描けません。ブラウザのデータを消すと、落書きも消えます。
- 画像としてドライブに保存したり、ノートに投稿したりしたときだけ、その画像がサーバーに送られます。やり方は、絵チャの[画像として保存・投稿する](./draw-room.md#画像として保存・投稿する)と同じです。

## 投稿フォームから描く

- 投稿フォームの落書きボタンから、新しく描くか、前の落書きの続きを描けます(ウインドウで開きます)。
- 「ノートに添付」で、描いた絵をそのままそのフォームに添付できます。

## ナビゲーションバー

「落書き」は、ナビゲーションバーの既定の並びに入っています。前から使っている人にも1回だけ追加されます(自分で外した場合は、また追加されることはありません)。
