# アンテナ

アンテナの受信ソースで、「フォローしているユーザーのノート」を選べます(JUICEのバッジ付き)。

## フォローしているユーザーのノート

- アンテナの持ち主がフォローしているユーザーのノートだけを拾います。
- 自分のノートや、フォローしていない人のノートは拾いません。
- キーワードなど、ほかの条件と組み合わせられます。たとえば、フォローしている人のノートのうち、特定の言葉を含むものだけを集められます。

::: info
本家のMisskeyでは、この受信ソースは選択肢から外されていて、中身も作られていませんでした(選んでも「全てのノート」と同じ動きでした)。Juice Serverでは、名前のとおりに動くようにしています。
:::
