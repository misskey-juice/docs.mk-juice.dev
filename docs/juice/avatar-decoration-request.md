# アバターデコレーション申請

一般ユーザーがアバターデコレーションの追加を申請できる機能です。仕組みは[絵文字申請](./emoji-request.md)と同様です。

## 申請方法

アバターデコレーション申請ページから、以下の項目を入力して申請します。

- デコレーション画像
- 名前
- 説明
- カテゴリ

カテゴリ・説明といった項目は、管理者設定で個別に必須化されている場合があります。必須の項目には「(必須)」と表示され、未入力の場合は申請ボタンが無効になります。複数件まとめて申請する場合は、未入力の項目があるカードのヘッダーに警告バッジが表示されます。

申請は却下または承認されるまで保持されます。承認されると、そのままアバターデコレーションとして利用できるようになります。却下された場合は理由が通知されます。もう一度申請したい場合は、新しい申請として出し直してください。審査待ちの間であれば、申請者自身が申請をキャンセル(取り下げ)することもできます。

## 申請前に準備しておくと良い項目

以下のような内容をあらかじめ用意しておくと、フォームへの入力がスムーズです。

```
デコレーション名:
説明:
カテゴリ:
```

- 画像の解像度は、縦横ともに512pxまでがおすすめです。

## 申請数の上限

同時に出せる申請(審査待ち)の件数には上限があります(既定3件)。また、連続申請を防ぐためのレート制限もあります。申請フォームには、現在の審査待ち件数・あと何件申請できるか・1回にまとめて申請できる上限(最大10件)が表示されます。

審査待ち件数の上限とは別に、1日あたりに送信できる申請回数にも上限があります(既定5回、直近24時間のスライディングウィンドウ)。申請フォームには、あと何回送信できるか・次に枠が回復する日時も表示されます。

## 申請画像の扱い

申請時に、審査完了後に画像を削除するかどうかを選択できます。チェックを入れた場合、承認・却下いずれの場合も審査完了時にDriveファイルが削除されます(承認時はデコレーション側に画像がコピーされるため、削除しても本体には影響ありません)。

## 審査待ちの申請の画像を差し替える

審査待ちの間は、申請した人が、申請の画像だけを差し替えられます。

- 自分の申請の一覧で、審査待ちの申請の「画像を差し替える」から、新しい画像を選びます(ドライブ・PC・URLから選べます。PCから選ぶときは、画像以外のファイルは選べません)。
- 差し替えると、一覧のサムネイルがその場で新しい画像に変わります。
- 「審査完了後に画像を削除する」にしていた申請では、使わなくなった前の画像を削除します(ほかの申請で同じ画像を使っている場合は削除しません)。
- 名前やカテゴリなど、画像以外の内容は変わりません。すでにアバターデコレーションになったものの画像を変えたいときは、「差し替え申請」を使ってください。

::: info モデレーター向け
審査の画面で見ていた画像が、その後に申請した人に差し替えられていた場合、承認・却下は「画像が差し替えられました」と表示されて断られます。一覧を読み直して、今の画像を確かめてから審査し直してください。
:::

## 審査(モデレーター向け)

- 審査画面で申請を選んで、まとめて承認・却下できます。まとめて処理した場合も、申請者への通知・メールとモデレーションログは1件ごとに残ります。
- 申請者が1回の送信でまとめて出した申請は、モデレーターへの新着通知とSystem Webhookを1つにまとめて送ります(通知には「ほかN件」が付きます)。

::: warning System Webhookを受け取っている場合
v3.19から、`avatarDecorationRequestCreated`のペイロードに件数の`count`と申請の一覧`requests`が加わりました。`id`・`name`・`category`は1件目の申請のものです。申請1件ごとにWebhookが届く前提で処理していた場合は、`requests`を見るように変更してください。
:::
