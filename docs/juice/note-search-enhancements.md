# ノート検索の強化

ノート検索画面に、以下の絞り込みができる高度な検索オプションを追加しています。

- キーワードのAND/OR切り替え
- 除外ワード
- 添付ファイルの有無
- CW(内容を隠す)の有無
- 返信の有無
- 投票の有無
- 公開範囲での絞り込み
- 投稿の言語での絞り込み(詳しくは[投稿言語](./post-language.md)をご覧ください)

検索に使われるキーワードは、重複を除いて16個までです。除外ワードは、空白で区切った語で128個までです。

これらのオプションは、[リアクション検索](./reaction-enhancements.md#リアクション検索)でも同様に利用できます。
